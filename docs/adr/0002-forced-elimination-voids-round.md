# 0002: Forced elimination during bidding voids the round

Status: accepted

The spec says a kicked or timed-out player is eliminated "as if they lost" and the game continues, but does not say what happens to the round in progress. Decision: if this happens during BIDDING the round is void and a new one is dealt without that player (the starter rotates as usual); during REVEAL the player is simply removed before the next round. If one player remains, that player wins.
